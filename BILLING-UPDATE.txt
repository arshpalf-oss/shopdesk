UPDATE AN EXISTING LOCAL INSTALLATION — NO REBUILD REQUIRED

1. Download a backup from Settings > Data & security before updating.
2. Stop shop desk with Ctrl+C in its terminal.
3. Extract shop-desk-billing-update.zip, then OPEN the extracted folder.
4. Copy ALL CONTENTS from inside it into your EXISTING app folder — the folder
   containing package.json. Merge folders and replace matching files.

   The required application changes are:
     dist/         Complete, already-built frontend
     src/          Updated frontend source
     server/       Updated PDF generation, API and settings validation
     printing.js   NEW shared printing module in the app's root folder

   Also included: updated README, Dockerfile, isolated tests and this guide.
   Do not copy only src/styles.css or only the dist folder for this update.
   Do not nest the update folder inside your app instead of merging contents.
5. From the same EXISTING app folder, run:

   npm start

6. Hard-refresh the browser: Ctrl+F5 on Windows/Linux, Command+Shift+R on macOS.

Keep the existing data/ folder and any custom DB_PATH unchanged. This update

HOW TO USE IT

A. Settings > Templates & printing
   Choose an invoice template, default format and 58/80 mm roll width. Save.
   Corporate is the default for existing clinics that have no print preference.
   Use "Show print preview" to preview an existing record without creating data.

B. Billing & invoices > New POS bill
   Search/scan products, choose client or walk-in, review quantities/prices, and
   select payment received. "Unpaid" remains the safe default. Select "Paid in
   full" only after money is actually received. Issue bill, then click Print or
   Download PDF. A failed issue cannot be printed as a successful sale.

C. Any saved invoice
   Use Output format to choose A4, Thermal 80 mm or Thermal 58 mm. Choose an A4
   template if needed. The current selection controls Print and Download PDF.
   Credit PDF follows the selected paper format too.

PRINTER SETUP & LIMITS

Install the printer manufacturer's standard driver. Select the matching roll
width, 100% scale, and turn browser headers/footers off. In a PDF viewer select
that same thermal printer/paper, not "fit to A4". Allow print popups if blocked.
Very long bills may require a custom roll length in your driver. Thermal PDFs
are content-sized and split into continuation pages above 1,000 mm per page.

Printing uses the normal driver/browser dialog. Direct ESC/POS, silent printing,
automatic paper cutting, automatic cash-drawer opening and card-terminal/payment
integration are not included. No physical thermal printer was connected during
testing; digital paper dimensions, generated content and workflows were tested.
UPI QRs are payment instructions, not automatic confirmation of a payment.
